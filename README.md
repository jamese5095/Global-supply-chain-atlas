# BG Global Supply Chain Atlas

BG国际供应链布局总览 · 六行业

在线访问：https://jamese5095.github.io/bg-global-supply-chain-atlas/

打开 `index.html` 即可查看离线页面。顶部保留BG总览和六个行业页面。

## 本版内容

- 来源链接复核：616条来源中删除27条、修正13条；589条保留。医药133→124条，错误归属及缺乏可复核原文的项目同步移除。逐条状态与限制见`source-link-audit.json`。

- 总览及六行业标题下统一展示“客户选取”和“案例范围”：每个子行业5家、头部企业定义、海外及跨境案例边界、背景与国内参考、历史及规划状态、原始地域范围。行业子类与客户数量按完整名册计算，不随筛选改变。

- 左上角固定“返回上一步”按钮，页面滚动时保持可见。返回可恢复之前的区域、国家、客户、业务筛选与滚动位置；无历史状态时返回BG首页。首页入口沿用Logo，不另设重复按钮。
- 首页策略表述统一采用“首先……其次……”。

- 首页增加十个区域的建议进入顺序，前三位为东南亚、欧洲、北美。点击优先级卡片与点击地图区域进入同一内容。
- BG区域页不展示案例依据栏目；全球页的案例依据与各行业页的案例内容保留。
- 区域业务特点、BG切入方向、现有能力依据全部展开，不折叠。顺丰能力部分不展示来源提示或链接；客户案例来源继续保留。
- 区域顺序综合考虑网络共用、当地能力、客户入口与短板获取路径，是战略研判，不按案例数量自动排名。选择业务类型只调整案例与数量，不改变区域顺序。
- 能力依据补充海外能力建设表的六个行业页。已交付、项目入口、在推进及较快复制方向分别表述；快速落地不等同已经建成，当前机会不等同已签约。
- BG十个区域页均移除“能力获取建议”栏目，保留区域业务特点、BG切入方向和现有能力依据。全球总览页继续展示该栏目，名称为“能力建设分析”。

## 数据口径

六行业明细与上一版一致，145家客户名册完整保留。BG热度包含486个供应链案例条目，涉及137家客户；境内参考和纯制造配套不计入BG热度。一个项目可有多个业务标签，17类业务数量不可相加为项目总数。

国家、区域共用及全球信息按原有范围保存，11个跨区域／全球条目不分摊为国家热度。历史及规划建设项目保留状态标记。案例数量用于观察资料集中度，不代表货量或实际网络利用率。

## 更新

- `data.json`、`input/`及原有表格导入流程维护六行业明细。
- `bg-content.json`维护区域判断、能力基础、建议顺序和获取路径；这是编辑分析内容，数量变化不会自动改写战略结论。
- `bg-core.js`维护BG数量汇总；`bg.js`和`bg.css`维护界面与交互；`navigation.js`维护跨行业及BG页面的返回历史；`scope-notes.js`统一维护客户选取定义与案例素材边界。
- 浏览器导入与六行业页面共用存储。导入行业表后回到BG，可重新汇总最新案例。

修改后运行 `python3 build.py`，生成内嵌地图、组件与数据的 `index.html`。该文件可单独分发；`page.html`是构建模板。静态托管以 `index.html` 为入口。

组件许可位于 `vendor/`。原六行业的表格字段、客户布局、承接主体及来源链接维持原有读取逻辑。

## 来源复核与旧资料

原始XLSX留作输入备份，未直接改写。`source-audit.js`识别完全匹配的已知旧快照，避免旧缓存、旧备份或旧表格导入覆盖已修正结果；用户后续新编辑不自动替换。`data.json`为本次已清理的发布数据。
